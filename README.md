## 🎯 Objetivo

Desenvolver, aplicar e testar estruturas de dados fundamentais usando Java, com foco em:

- Listas estáticas, encadeadas e genéricas
- Pilhas e filas com exceções
- Árvores binárias e n-árias
- Busca e ordenação
- Tabelas de dispersão (Hashmap)
- Testes automatizados com JUnit
- Documentação modular por unidade

## 📂 Conteúdo por Unidade

- **Unidade 01** – Lista Estática, Lista Genérica, Lista Encadeada
- **Unidade 02** – Pilha com Vetor, Lista, Exceções
- **Unidade 03** – Árvores Binárias, N-Árias, Caminhamentos
- **Unidade 04** – Buscas (linear, binária), Hashmap, Ordenações (Quick, Merge, Bolha)
- **Unidade 05** – Organização de aplicações, testes finais

---

## 🚀 Como Executar

1. Abra um terminal ou IDE com suporte a Maven
2. Acesse o diretório do projeto desejado (ex: Lista01)
3. Execute:
```bash
mvn clean install
```

Ou importe o projeto no **NetBeans** e execute os testes.
